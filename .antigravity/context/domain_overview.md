# Product Overview

TixLoop is a circular ticketing marketplace designed to reduce ticket waste, prevent scalping, and create a safer resale ecosystem for event tickets in Indonesia.

The platform focuses on:
- fair ticket resale
- anti-scalper enforcement
- waste prevention
- trust-oriented transactions
- SDG 12.5 alignment

---

# Core Problems

## Ticket Waste
Many tickets become unusable because users suddenly cannot attend events.

## Scalping
Secondary markets are dominated by unfair pricing and mass ticket hoarding.

## Unsafe Resale
Most ticket resale transactions happen without escrow or ticket verification.

## Lack of Transparency
Users cannot validate ticket ownership or legitimacy.

---

# Core Mission

Transform tickets into circular digital assets that continue circulating safely until the event begins.

# Core Innovation

## Burn Prevention Engine

Automatic pricing adjustment mechanism that lowers ticket prices as the event approaches.

Objectives:
- reduce unused tickets
- improve affordability
- improve ticket circulation
- reduce economic waste
