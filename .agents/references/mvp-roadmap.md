# mvp-roadmap.md

*   **Purpose**: Strategic MVP roadmap phases and prioritisations.
*   **Scope**: Project timeline and feature sequencing.
*   **Ownership**: Product Owner.
*   **Priority**: High.
*   **Dependency**: None.

---

## 1. Feature Priority order

1.  **Authentication**: Sanctum secure tokens, login, and registration.
2.  **Marketplace Flow**: Ticket listings, filtering, search, and details.
3.  **Ownership Integrity**: Verification history and circular transfer logic.
4.  **Burn Prevention**: Price decay schedules and countdown mechanics.
5.  **Escrow Simulation**: Security holdings and dispute freezes.
6.  **Waste Dashboard**: SDG 12.5 metrics (waste recovery rate, ticket circularity).

---

## 2. Roadmap Phases

### Phase 1 — Foundation
*   Email-based registration and login flows.
*   Sanctum bearer token verification.
*   User identity validation endpoints.

### Phase 2 — Marketplace
*   Listing creation.
*   Listing search, filtration, and detail pages.
*   Ticket state management.

### Phase 3 — Ownership
*   Transfer verification workflows.
*   Listing owner history logs.
*   Ownership validation checks.

### Phase 4 — Burn Prevention
*   Auto price decay based on deadline.
*   Floor price validation constraints.
*   Price decline countdown logic.

### Phase 5 — Escrow
*   Escrow holding simulation.
*   Conditions to release payments.
*   Dispute transaction freezing.

### Phase 6 — Dashboard
*   SDG waste reduction calculations.
*   Circulation volume metrics.
*   Recovery rates display.
