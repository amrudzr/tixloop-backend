## 1. Process Flow

### Step 1: Requirements Intake
*   Read core decisions, prioritize list, and scoping documents.

### Step 2: Structure Definition
*   Define task objective.
*   Define scope boundaries (included vs excluded items).
*   Assess dependencies, risks, and technical impacts.

### Step 3: Priority Classification
Assign a priority level:
*   `critical`
*   `important`
*   `optional`
*   `future_scope`

### Step 4: Planning Log
Write a log file inside `.antigravity/logs/planning/` describing the planning output, using the format `[sequence]_[YYYY-MM-DD]_[slug].md`.
